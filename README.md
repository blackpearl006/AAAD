# Age &amp; gender Aware Alzhimer's Detection (AAAD)
This repository contains the code and resources for the study “Age-Aware MCI Detection”, which explores machine learning models to detect Mild Cognitive Impairment (MCI) while incorporating age as a critical factor. The study evaluates baseline and proposed models across various metrics, including accuracy, precision, sensitivity, specificity, and F1-score.
